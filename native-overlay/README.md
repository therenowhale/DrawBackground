# DeskSketch — рисование поверх рабочего стола

Это небольшая нативная утилита macOS. В обычном состоянии её прозрачные окна не ловят мышь — рабочий стол и приложения работают как обычно. В режиме рисования прозрачное окно становится активным и можно рисовать прямо поверх экрана.

## Запуск

В Terminal из папки проекта:

```bash
cd native-overlay
chmod +x run.sh
./run.sh
```

В строке меню macOS появится значок карандаша.

1. Нажмите значок карандаша → **Начать рисовать**.
2. Рисуйте поверх рабочего стола (и любых открытых окон).
3. Снова нажмите значок → **Закончить рисовать**, чтобы клики снова попадали в macOS.
4. **Очистить рисунок** стирает все линии.

Аварийный выход из режима рисования: нажмите **Esc** или правую кнопку мыши. Чтобы закрыть утилиту полностью — **⌘Q**.

Рисунок пока живёт только до закрытия приложения. Он не связан с Plash: Plash оставьте для SVG-обоев, а DeskSketch используйте, когда хотите рисовать прямо поверх экрана.

## Требования

Нужны Command Line Tools for Xcode (`swiftc`). Полный Xcode не требуется.

Если компиляция говорит, что версия SDK не поддерживается Swift, обновите Command Line Tools в **System Settings → General → Software Update**, затем повторите `./run.sh`. Это означает, что macOS обновила компилятор раньше SDK; к самому проекту ошибка не относится.
